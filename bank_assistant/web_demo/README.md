# نسخة تجريبية داخل Claude / Version d'essai dans Claude

صفحة واحدة تعمل داخل Claude (Artifact) لتجربة فكرة التطبيق دون خادم: رفع الملفات وقراءتها والبحث فيها يتم في المتصفح، والإجابة يكتبها Claude من المقاطع المسترجعة.

- `core.js`: نسخة JavaScript من معالجة النص في `bankrag/textproc.py` و`bankrag/ingest.py` (التطبيع، ترتيب النص العربي في PDF، تقسيم المقاطع، البحث BM25). تعطي نفس نتائج نسخة Python.
- `app.js`: منطق الصفحة (التخزين، قراءة PDF/Word/Excel، المحادثة).
- `template.html`: الواجهة والتصميم.
- `python build.py` يجمعها في ملف واحد `bank-assistant.html`.

الميزات نفسها كالتطبيق الكامل: قراءة صفحات PDF الممسوحة ضوئياً (يقرأ Claude صورة الصفحة، حتى 30 صفحة للملف)، وزر «إجابة شاملة»، وتلخيص وثيقة كاملة مع روابط إلى الصفحات.

هذه النسخة للتجربة فقط: مقاطع الوثائق تُرسل إلى Claude. للاستعمال الفعلي في البنك استعمل التطبيق الكامل في المجلد الأعلى مع نموذج يعمل على خوادم البنك.
