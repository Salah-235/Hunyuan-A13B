# نسخة بمفتاح OpenAI / Version avec clé OpenAI

ملف واحد `bank-assistant-openai.html` يُفتح مباشرة في Chrome على الكمبيوتر أو هاتف أندرويد، دون خادم ودون تثبيت.

- ضع مفتاح OpenAI من زر الإعدادات (رمز الترس) ثم اضغط «حفظ واختبار».
- الوثائق تُقرأ وتُفهرس داخل المتصفح وتُحفظ في هذا الجهاز فقط (IndexedDB).
- المفتاح يبقى في النافذة المفتوحة فقط، إلا إذا اخترت «تذكّر المفتاح على هذا الجهاز».
- عند كل سؤال تُرسل مقاطع الوثائق المتعلقة به إلى OpenAI.
- **ملفات PDF الممسوحة ضوئياً**: كل صفحة بلا نص تُرسل صورتها إلى نموذج OpenAI المختار ليقرأها (حتى 100 صفحة للملف). يجب أن يكون النموذج قادراً على قراءة الصور (gpt-4o-mini أو gpt-4.1-mini مثلاً)، وتظهر على هذه المقاطع شارة «OCR».
- **إجابة شاملة**: زر تحت خانة السؤال يجعل المساعد يقرأ 24 مقطعاً بدل 8، للقوائم والأسئلة العامة.
- **تلخيص وثيقة كاملة**: زر بجانب كل وثيقة. الوثائق الطويلة تُقرأ على أجزاء ثم تُجمع، ويُحفظ الملخص في هذا الجهاز.
- مكتبات قراءة PDF وWord وExcel تُحمَّل من jsDelivr (أو unpkg) مع بصمة تحقق (SRI)، فلا تعمل أي نسخة معدَّلة منها.

تنبيه أمني: في Chrome تشترك كل ملفات HTML المفتوحة من الجهاز في نفس التخزين، فلا تفتح في نفس المتصفح ملفات HTML مجهولة، واستعمل مفتاح OpenAI خاصاً بحد إنفاق منخفض.

لإعادة بناء الملف بعد تعديل `app.js` أو `template.html`: `python build.py`.
